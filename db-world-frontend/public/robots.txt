# ─────────────────────────────────────────────────────────────
# AI TRAINING CRAWLERS — BLOCKED
#
# meta-externalagent renders the SPA, so it does not just fetch pages: it
# executes the JavaScript and fires every XHR each page makes. One record page
# is ~7 API calls (catalog, similar, reviews, reviews/mine, media-info, …), and
# it was walking the catalogue — thousands of requests an hour against a single
# Raspberry Pi, for content Google is not even indexing.
#
# These groups are listed BEFORE `User-agent: *` by convention only. A crawler
# obeys the single most specific group that matches its token and ignores the
# rest, so each of these sees "Disallow: /" and never reads the Allow rules.
#
# DELIBERATELY NOT BLOCKED:
#   facebookexternalhit, facebot  — the WhatsApp/Facebook LINK PREVIEW crawlers.
#     Different bots from meta-externalagent, and SocialPreviewController exists
#     to serve them. Blocking these would break every shared record card.
#   Applebot                      — feeds Siri and Spotlight search.
#   ChatGPT-User, OAI-SearchBot   — user-initiated fetches and ChatGPT search.
#     These send referral traffic rather than take it; blocking them costs
#     visitors. Add them here if that stops being true.
#
# Google-Extended and Applebot-Extended are not crawlers at all — they are
# robots tokens that control whether Google and Apple may use already-crawled
# content for AI training. Disallowing them has NO effect on Search ranking.
# ─────────────────────────────────────────────────────────────

# ─────────────────────────────────────────────────────────────
# RECORD PAGES: crawl, but do not index.
#
# They are NOT disallowed, and that is deliberate. Every word on one comes from
# TMDB, so ~2,300 of them are scraped metadata at scale — which is what Google's
# September 2026 AdSense review meant by "low value content", and they are gone
# from the sitemap for that reason. But a Disallow would be the wrong tool: it
# blocks the fetch, so Google never sees the noindex it would need to obey, and
# it also cuts the links from a record page through to its collection and genre
# pages. SeoRenderController sends `noindex,follow` instead, which needs the
# crawl to happen.
#
# Ads still serve on them: AdSense does not require a page to be indexed.
# ─────────────────────────────────────────────────────────────
